# 正式上线接入清单

当前版本已完成业务闭环和私有部署。以下外部资料到齐后，才能切换真实生产通道。

## 微信小程序与支付

- 已认证小程序的 AppID、AppSecret、业务域名和隐私协议。
- 微信支付商户号、API v3 密钥、商户证书/私钥、平台证书或公钥、支付回调域名。
- 订阅消息模板 ID：支付成功、门店已接单、已备妥、退款结果。
- 微信手机号授权及客服入口方案。

## 银豹与门店硬件

- 银豹开放平台接口文档、门店号、应用凭据和测试环境。
- 商品 SKU、规格、价格、库存和订单状态的字段映射及主数据归属。
- 银豹异常重试、对账和人工补偿联系人。
- 小票机型号、连接方式、打印模板、失败补打流程。

## 门店资料与运营规则

- 正式门店名、地址、电话、营业时间、取货点指引和门店照片。
- 正式商品、图片、价格、包装费、库存和过敏原信息。
- 可预约时段、容量、提前下单时间、截单时间及临时闭店规则。
- 退款、取消、逾期未取、食品安全、用户与隐私协议文本。
- 门店员工名单、角色权限、离职回收和审计保存期限。

## 上线门槛

- 支付回调签名、金额和订单归属校验通过；重复回调保持幂等。
- 银豹双向商品/库存/订单对账通过，失败有告警与人工补偿入口。
- 真实打印机完成接单、补打和断网恢复测试。
- 微信开发者工具及真机完成下单、支付、通知、核销、退款验收。
- 生产 secrets 只存平台密钥管理，仓库和前端包中不存在任何凭据。
