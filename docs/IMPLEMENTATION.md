# 小雨面包预约自提业务版

## 已交付范围

- 顾客端：今日菜单、实时余量、自提时段、购物袋、确认订单、模拟微信支付、订单进度、动态取餐码。
- 门店端：新订单提醒、接单、制作、备妥、取餐码核销、生产批次、时段负载、库存及临时售罄。
- 数据层：Cloudflare D1 持久化商品、时段、订单、明细、审计日志和第三方集成事件。
- 交易保障：10 分钟库存及时段预占、支付后转已售、数据库触发器防超卖、幂等下单、订单状态机、取餐码哈希校验。
- 集成边界：微信支付、订阅消息、云打印及银豹均通过 adapter 接口调用；当前私有站点使用 demo provider。
- 履约边界：只支持预约到店自提，没有同城配送、收货地址、骑手或配送费。

## 核心状态机

`待支付 → 待接单 → 已接单 → 制作中 → 待取货 → 已完成`

待支付阶段锁定商品及一个取货时段；模拟支付成功后解除预占并计入已售。门店只能按顺序推进，待取货订单必须使用该订单的动态取餐码核销。

## 本地运行与验证

```bash
npm install
npm run db:generate
npm run dev
npm run lint
npm test
```

本地开发由 Cloudflare Vite 插件提供 D1 binding。部署通过 `.openai/hosting.json` 中的 `DB` binding 和 `drizzle/` 迁移创建远端数据库。

## 接口

- `GET /api/bootstrap?surface=customer|merchant`：商品、时段与最近订单。
- `POST /api/orders`：幂等预占、模拟支付确认及集成同步。
- `GET /api/orders/:id`：查询订单；顾客只能读取自己的订单。
- `POST /api/orders/:id/transition`：门店推进状态或使用取餐码核销。
- `POST /api/products/:id/availability`：门店临时售罄或恢复销售。

## 权限说明

私有 Site 会向服务端传递已认证用户 ID 与邮箱，顾客订单据此隔离。当前同一个私有演示成员可切换门店工作台，门店变更接口还要求演示角色头。正式微信上线时，应将顾客身份替换为微信 `openid`，将门店权限替换为员工账号与服务端白名单；客户端角色值不能作为正式授权依据。
